# 시린지펌프 하드웨어 테스트 툴 (v1.3.0)

시린지펌프(SY-01B / Tecan XCalibur·RS485)가 연결된 컴퓨터에서 켜서, 브라우저 버튼으로
펌프를 시험하는 **순수 벤치 도구**다. 운영 개념(향료·레시피·포트 매핑·세척)은 없다 —
**포트는 그냥 번호이고(기기의 밸브 보고를 따르되 최대 12 — 양 매뉴얼 공통 상한), 프리미티브는
흡입/배출이며, 안 되는 조합은 기기가 err로 정직하게 거부한 것을 그대로 보여준다.** 주문·제조·서버 연동 없음.

> 2026-09-03 개편 — 이전의 "admin 유지보수 화면 미러"에서 벤치 순수형으로 재정의했다.
> 배경·구조·검증 기록: `developer/hey_senlyt/v1.3.0/99_daily/2026-09-03-하드웨어툴-벤치개편-지문게이트.html`

## 운영 스택과 "똑같이 동작"하는 이유

이 툴은 펌프 제어를 **재구현하지 않는다.** 운영 pi daemon 패키지 `senlyt_pi`(v1.3.0 커밋 핀,
`requirements.txt`)를 그대로 설치해서 그 어댑터로 펌프를 구동한다:

| 이 툴의 동작 | 실행되는 운영 코드 |
|---|---|
| [연결] | `serial_port_discovery.list_candidate_ports` + `pump_health.discover_pumps` (daemon 부팅과 동일) + **모델 지문 대조**(아래) |
| ① 초기화 | `initialize_polled` — **배출구를 향한 Z**(정의 2026-09-03: 홈 복귀 = 실린 액 전량 배출 동반이라 방향 필수. 분배=`Z{힘},{p},{p}`+주차 `I{p}` / 3-way=OR 선회전→Z→OR 재확정·폴 조기완료) |
| ② 흡입 | `aspirate` — (포트 지정 시 회전) → 절대 위치 `A{steps}` + 명시 속도/경사 |
| ② 배출 | `rotate_valve` + `plunger_to(현재-요청 steps)` — **정한 양만큼 하강**(실린 양 초과는 400). 어댑터 `dispense()`(전체 사이클)를 빌리지 않는다(그 경로는 배출 전 풀스트로크 흡입을 먼저 쏨 — R9.5 P0) |
| ⛔ 긴급 정지 | `emergency_stop_all` (daemon 감시 스레드와 동일 호출 — 정지 프레임은 기종 방언: SY-01B=`TR`·XCalibur=`T` 단독, R 재개 위험 §3.5.5) + 펌프별 `?` 프로브로 도달 검증. 복구는 ①만 |
| 기주 밸브(밸브 제어 탭) | GPIO 솔레노이드 — "밸브"는 이것뿐(회전 헤드는 펌프의 일부) |
| 상태 점검 | `health_probe` (daemon 하트비트와 동일 판정) |

용량→스텝 파생·속도 클램프·에러 분류·ack-tolerant·estop 래치 전부 pi daemon 코드가 그대로
돈다. SY-01B/Tecan 문법(`A`/`I`/`Z`…)을 아는 자리는 어댑터뿐이라는 운영 경계도 그대로다.

## 모델 지문 게이트 (2026-09-03)

Runze(SY-01B)와 Tecan(XCalibur)은 문법이 비슷해 설정이 틀려도 "연결까지는" 된다 — 그때
기종 전용 설정 명령(`U…`)이 다른 실물에 날아가는 실누수가 있었다. 2겹 방어:

- **어댑터(큰길)** — sy01b 어댑터가 초기화 3경로(`_setup`·polled·broadcast) 전부에서 기종
  프레임 발사 직전 `&` 지문을 읽고, Tecan 패턴(`^30\d{6}\s+[A-Z]`) 매치 시 -1003으로 거부
  (U 프레임 0건). 미지 응답은 통과(fail-open) + 판독 실패는 1.5s·주소당 3회 상한 후 세션 포기.
- **툴(연결단)** — 연결 성공 직후 전 펌프 지문 대조, Runze 설정 + Tecan 실물이면 연결 자체를
  409로 거부·정리. 우회는 API(`allowFpMismatch`)로만 — UI 체크박스는 2026-09-04 제거.
- 역방향(Tecan 설정 → SY-01B 실물)은 SY-01B `&` 지문 미실측이라 하드 차단은 없다(백로그).
  다만 연결단이 **Tecan 지문이 하나도 확인 안 되면(무응답 포함) 경고**를 띄운다 — 이 방향은
  err 없이 요청량의 1/4만 나오는 무성 방향이라 경고를 무시하지 말 것(2026-09-03 5팀 검증).

## 구조 (헥사고날 — 의존 방향은 core ← adapters ← service ← web ← app.py)

```
app.py               진입점(조립만) — bootstrap.sh/start.py 는 그대로 이걸 실행
pl2303py.py          PL2303 HXN 유저스페이스 드라이버(맥 등 커널 드라이버 없는 호스트용)
hwtool/core/         도메인: 클램프 범위·센소리움 레지스트리 (순수 → 단위테스트)
hwtool/adapters/     아웃바운드: 기기모델→EnginePort 구현체 결선(SY-01B/Tecan)·GPIO 밸브
hwtool/service/      유스케이스: STATE·락·게이트·연결/프리미티브 오케스트레이션 (Flask 무의존)
hwtool/web/          인바운드: Flask 라우트(얇게) + UI HTML
tests/               core·service·web 배선을 시리얼/서버 없이 검증 (pytest)
```

인터페이스(포트)는 새로 만들지 않는다 — 운영 pi daemon 의 `senlyt_pi.ports.EnginePort` 가
그 포트이고, 이 툴은 소비자다. 테스트: `PYTHONPATH=../heysenlyt-pi/src:. python3 -m pytest -q tests/`
(pi 소스가 형제 폴더에 있을 때 — pip 설치 환경이면 `PYTHONPATH=.`).

## ⚠️ 먼저 이해할 것 — USB의 역할

| 항목 | USB로 되나? |
|------|:----:|
| 펌프에 **명령 전송**(회전/흡입/배출) | ✅ USB→USB-RS485 어댑터→펌프 |
| 펌프 **모터 구동 전원**(24V) | ❌ **별도 SMPS 필요** — USB로는 못 돌림 |

USB는 통신선이다. 별도 24V 전원이 없으면 명령이 나가도 물리적으로 움직이지 않는다.
통신 성립만 확인하려면 "상태 점검"의 링크 판정(정상/무응답)으로 충분하다.

맥 등 PL2303 커널 드라이버가 없는 호스트에선 `/dev` 포트가 안 보여도 된다 — 자동으로
유저스페이스 경로(`pyusb:pl2303`, `pl2303py.py`)로 폴백해 파이썬만으로 구동한다
(pyusb + libusb-package, pip 설치뿐).

## 사용 순서

1. **설정** — 센소리움 버전(= 기기 정의: 펌프 모델·펌프 수·통신 방언)과 시린지 용량을 고른다.
   기본값 = 식향 Runze + 0.25mL. 버전의 펌프 기기 모델(SY-01B / Tecan XCalibur)이 어댑터
   구현체와 스텝 축(12000/3000)을 함께 결정한다 — 인터페이스(EnginePort)는 동일, 구현체만
   기종별로 갈아끼운다. 설치된 senlyt-pi 에 그 기종 구현체가 없으면 연결을 거부하고 ⚠️ 표기.
2. **[연결]** — 설정을 다 고른 뒤의 명시 행위(오픈-클로즈). [연결 해제]까지 유지되고, 자동
   재연결은 없다. 연결 중 버전을 바꾸면 진행 중이던 연결은 중단된다. 지문 불일치면 409.
   포트 고정은 환경변수 `SENLYT_SERIAL_PORT`.
3. **① 초기화** — 정의: **배출구를 향한 채 진행하는 기준 리셋**(매뉴얼 정식 명칭은 `[Z]`
   Initialize — "약한"은 용량 파생 힘(반력/⅓력)의 우리 수식어). 홈 복귀는 플런저를 끝까지 밀므로
   실린 액체가 **전량 배출**된다(피할 수 없음 — 방향만 통제 가능). 그래서 배출구 선택이 **필수**:
   분배밸브=포트 번호(그 포트를 향한 채 홈+주차), 3-way=배출측(자동 선택). 연결 후 첫 단계 —
   이걸 해야 ②가 열린다(estop 복구도 이 버튼).
4. **② 흡입·배출** — 포트 콤보는 연결 시 읽은 기기의 밸브 보고(`?76`)를 따른다("활용-아니면-무시"):
   방향형(3-way 등)=입력측(IR)/배출측(OR), 분배형=P1~PN, 미판독=P1~12 폴백(12 = 양 매뉴얼 공통
   최대 — 12 초과 포트는 어느 매뉴얼에도 없음). 모든 동작은 포트/방향 **명시 선택 필수**(암묵적
   "현 방향 유지" 없음 — 미선택은 400). 양(슬라이더)·속도(50~6000Hz)·가속 경사(L1~20)를 정해
   [흡입]/[배출] — **둘 다 정한 양만큼**(흡입은 절대 위치라 반복해도 축적 없음, 배출은 실린 양
   초과 시 400으로 거부하며 실린 양을 알려준다).
   안 맞는 선택은 기기가 err3로 거부. ⚠️ `?76`은 자기 신고(U 설정 되읽기)라 밸브 교체 후
   재설정 안 된 개체는 거짓말한다 — 판정 근거로는 쓰지 않는다.
5. 이상 시 **⛔ 긴급 정지** — 정지 프레임 발송(기종 방언: SY-01B=TR·XCalibur=T) + 도달 검증(전 펌프 무응답이면 실패 보고 — 그땐 24V
   전원을 직접 차단). 래치가 서면 복구(초기화) 외 모션은 잠긴다.
6. **밸브 제어 탭** — 기주 솔레노이드(기주 1·기주 2, GPIO) 열림/닫힘 시험.

로그 창에 pi daemon의 구조화 로그가 그대로 흐른다(복사 📋·지우기 🗑, 시리얼 왕복 원문은 DEBUG).

## 외부 접속·보안

인증이 없다 — 같은 네트워크 누구나 펌프를 움직일 수 있다. **정비할 때만 켜고, 끝나면 끈다.**
(부팅 자동시작으로 설치했다면 정비 후 `sudo systemctl stop heysenlyt-hardware-test-tool` 권장.)
외부 공개가 필요하면 `./run_with_tunnel.sh`(Cloudflare 임시 터널)를 쓰되 같은 경고가 적용된다.

**이 도구는 벤치 도구이지 운영 데몬(senlytd)이 아니다** — 배관·액체 없는 벤치의 펌프에 쓴다.
운영 기기(배관 연결·senlytd 설치)에는 쓰지 않는 것이 원칙: [초기화]의 Z는 펌웨어 기본
포트로 밸브를 돌리고 주차하므로 배관된 기기에선 액체를 빨았다 버릴 수 있다(2026-07-21 실기기
확정 사고 형태). senlytd가 실행 중이면 연결 자체를 거부한다(같은 RS485 버스를 두 프로세스가
잡으면 프레임이 섞인다). 참고 — 매뉴얼(§4.3.1)은 건식(무액체) 구동이 씰을 소모한다고 경고한다:
벤치 실측은 그 소모를 감수하는 운영 결정이다.
